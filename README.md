# これはなに
規則案をLaTeXで作成するのを支援するパッケージです。

# jcounter.sty
これは漢数字やイロハなどを出力するパッケージで、[GitHub上](https://github.com/puripuri2100/Jcounter)で管理されています。
joubun.styに必須です。

# 使い方
基本的には、puripuri2100様の[Qiitaの記事](https://qiita.com/puripuri2100/items/b094118849d6ae7b3a9e)を読んでみてください（今後付け加えていく予定）。

以下に、追加したコマンドの説明を記します。
## \sakujotext[#1]{#2}{#3}
「第◯条　削除」などを出力するためのコマンドです。

第一引数には、削除する見出しの種類を入力します。例えば、「第◯条」を削除するときには、[jou]とします。<br>
第二引数には、削除する見出し番号を入力します。例えば、「第三章」を削除するときには、{第三章}とします。<br>
第三引数には、本文を入力します。例えば、「削除」とするときには、{削除}とします。
## \sakujoとの関係
\sakujotextは\sakujoと併用することを前提としています。というのは、\sakujotext自体にはカウンタを進める機能が無いためです。

このようにカウンタ進行と紙面表示を分離したのは、複数の条文を削除する場合に、カウンタ進行と紙面表示を同時に処理することが非常に困難であるためです。<br>
例えば、「第五条から第八条まで　削除」を表示する際、一気にカウンタを3進める必要があります。まだ単なる「条」なので簡単ですが、ここに枝番号が絡んでくると別種のカウンタが混ざり、処理が複雑になります。枝番号の枝番号や枝番号の枝番号の枝番号なんかもありますので、それらも関わると……はい。<br>
なので、条文を削除する際には以下のように使って下さい。<br>
    % \jou{あああああ}
    \sakujo\sakujotext[jou]{第◯条}{削除}

もし複数の条文を削除する際には以下のように使って下さい。
    % \jou{あああああ}
    \sakujo
    % \jou{いいいいい}
    \sakujo\sakujotext[jou]{第◯条から第△条まで}{削除}
もし複数の条文のうちに枝番号がある場合には、条、項、号はそれぞれ第一引数にjou、kou、gouを入れて下さい。処理自体はjouもedajouもedaedajouも同じです。
    % \jou{あああああ}
    \sakujo
    % \edajou{あいいいい}
    \sakujo
    % \edaedajou{あいううう}
    \sakujo\sakujotext[jou]{第◯条から第◯条の△の◇まで}{削除}
