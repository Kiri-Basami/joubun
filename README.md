# これはなに
規則案をLaTeXで作成するのを支援するパッケージです。

# jcounter.sty
これは漢数字やイロハなどを出力するパッケージで、[GitHub上](https://github.com/puripuri2100/Jcounter)で管理されています。
joubun.styに必須です。

# 使い方
基本的には、puripuri2100様の[Qiitaの記事](https://qiita.com/puripuri2100/items/b094118849d6ae7b3a9e)を読んでみてください（今後付け加えていく予定）。

以下に、追加・変更したコマンドの説明を記します。
## \jou[#1]{#2}
puripuri2100様の記事では「見出しについては括弧も付けて書いてください」とありますが、括弧を付けずとも括弧が生成されるようになっています。例えば、
```tex
\jou[基本原則]{私権は、公共の福祉に適合しなければならない。}
```
とすれば、

> 　**（基本原則）**<br>
> **第一条**　私権は、公共の福祉に適合しなければならない。

となります。
## \sakujotext[#1]{#2}{#3}
「第◯条　削除」などを出力するためのコマンドです。

第一引数には、削除する見出しの種類を入力します。例えば、「第◯条」を削除するときには、`[jou]`とします。<br>
第二引数には、削除する見出し番号を入力します。例えば、「第三章」を削除するときには、`{第三章}`とします。<br>
第三引数には、本文を入力します。例えば、「削除」とするときには、`{削除}`とします。
### \sakujoとの関係
\sakujotextは\sakujoと併用することを前提としています。

<details>
<summary>なんで併用する必要なんかあるんですか</summary>
\sakujotextにカウンタ進行機能が無いためです。ではなぜその機能を着けなかったのかといえば、複数の条文を削除する場合にカウンタ進行と紙面表示を同時に処理することが非常に困難であるためです。<br>
例えば、「第五条から第八条まで　削除」を表示する際、一気にカウンタを3進める必要があります。まだ単なる「条」なので簡単ですが、ここに枝番号が絡んでくると別種のカウンタが混ざり、処理が複雑になります。枝番号の枝番号や枝番号の枝番号の枝番号なんかもありますので、それらも関わると……はい。
</details>

条文を削除する際には\sakujoと\sakujotextを次のように使って下さい。
```TeX
% \jou{あああああ}
\sakujo\sakujotext[jou]{第◯条}{削除}
```
あるいは次のように使って下さい。
```
% \jou{あああああ}
\sakujo
\sakujotext[jou]{第◯条}{削除}
```
もし複数の条文を削除する際には以下のように使って下さい。
```TeX
% \jou{あああああ}
\sakujo
% \jou{いいいいい}
\sakujo\sakujotext[jou]{第◯条から第△条まで}{削除}
```
もし複数の条文のうちに枝番号がある場合には、条、項、号はそれぞれ第一引数にjou、kou、gouを入れて下さい。第◯条と第◯条の△、第◇条をまとめて削除するときには、jouを使って下さいということです。<br>
処理自体は本番も枝番も枝番の枝番もその先も同じだからです。
```TeX
% \jou{あああああ}
\sakujo
% \edajou{あいいいい}
\sakujo
% \edaedajou{あいううう}
\sakujo\sakujotext[jou]{第◯条から第◯条の△の◇まで}{削除}
```
